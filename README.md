# Bevásárlólista alkalmazás

## Projekt leírása
A projekt célja egy egyszerű, böngészőben használható bevásárlólista-alkalmazás fejlesztése, amely segíti a felhasználókat a vásárlás megtervezésében.

## Funkciók
- Termékek hozzáadása és törlése
- Termékek szerkesztése
- Megvásárolt termékek megjelölése
- Termékek keresése
- Bevásárlólista automatikus mentése

## Használt technológiák
- HTML
- CSS
- JavaScript
- localStorage (helyi adattárolás)

## Használat
Az alkalmazás az `index.html` fájl böngészőben történő megnyitásával indítható.

## Fejlesztés
A projekt 3 fős csapatmunkában készül a Rendszerfejlesztési technológiák tantárgy keretében.

A követelmények a `docs/requirements.md` fájlban találhatók.
